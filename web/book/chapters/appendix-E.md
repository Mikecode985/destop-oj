# 附录 E　习题提示与答案要点

> 提示只给"第一步怎么想"，代码请自己写；先卡 20 分钟再看这里。

## E.1 第 1 章　从"会语法"到"能做题"

1. 提示：提交一道 A+B，看清 AC、WA、RE 的含义。
2. 提示：数组开 5 格却用 a[1..5]，越界；循环改 0..4。
3. 提示：1 秒约 10^8 次：线性可过，平方级超时。
4. 提示：先枚举 465 个区间；再试前缀和，和转负清零。
5. 提示：查多测清空、溢出、n=1、取模为负。

## E.2 第 2 章　C++ 基础补课

1. 提示：和与 10^18 都开 `long long`；平均数用 `double`。
2. 提示：10^10 超过 `int` 上限，`sum` 要开 `long long`。
3. 提示：读 n 后换行残留；先 `getline` 吃掉或 `cin.ignore()`。
4. 提示：每轮找最大换到第 i 位，共 3 轮。
5. 提示：`getline` 读整行，再 `rfind(' ')` 切价格排序。

## E.3 第 3 章　STL 速成

1. 提示：`sort` 后 `unique` 取新尾，再 `erase` 到末尾。
2. 提示：`map<string,int>` 边读边 `++`，自动按字典序。
3. 提示：先 `resize` 成 n 行 m 列，再逐行累加。
4. 提示：范围 for 里 `erase` 使迭代器失效，改 `it=erase(it)`。
5. 提示：`map` 按类别分组，组内按单价排序。

## E.4 第 4 章　复杂度：为什么程序会超时

1. 提示：第一段 O(n)，第三段 O(10n)；只有嵌套是平方。
2. 提示：8×10^9 次必超时，4×10^6 次能过。
3. 提示：换 `'\n'`、关同步、把 `a[i]` 提到内层外。
4. 提示：4000×4000×4B=64MB，256MB 够用，别开两份。
5. 提示：等比和小于 2n；n=10^6 时不到 2×10^6 次。

## E.5 第 5 章　模拟：把生活翻译成代码

1. 提示：记当前层，累加层差与停留秒数。
2. 提示：`t%90`：绿 [0,30)、黄 [30,33)、其余红。
3. 提示：折成距公元 1 年的天数再减。
4. 提示：方向数组右下左上，越界或已填就换向。
5. 提示：切出数与运算符，乘除先算再加减。

## E.6 第 6 章　枚举：先能算对，再算快

1. 提示：公鸡 0..20、母鸡 0..33，小鸡由 100 减出。
2. 提示：枚举 `mask` 到 `(1<<n)-1`，逐位累加判 S。
3. 提示：枚举 a、b、c 到 `sqrt(n)`，d 由平方差开根。
4. 提示：只需扫 1..n 各算数位和，`O(n log n)` 能过。
5. 提示：折半：前半和排序，后半二分查 S−sum。

## E.7 第 7 章　排序与二分

1. 提示：手写用 `l=1`、`r=n+1` 左闭右开；`upper_bound` 减 `begin`。
2. 提示：`mid` 向下取整配 `l=mid` 会打转，改 `(l+r+1)/2`。
3. 提示：`check(H)` 是 Σmax(0,h[i]−H)，随 H 递减再二分。
4. 提示：`check(W)` 贪心数车 ≤k；W 从 `max(w)` 到总和二分。
5. 提示：f(1)<0<f(2)，循环 100 次按中点符号缩区间。
6. 提示：造 [真,假,真]，二分就停在假谷。

## E.8 第 8 章　贪心：眼前的便宜该不该占

1. 提示：面值 1、5、11 凑 15：贪心 5 张，最优 3 张。
2. 提示：小岛化区间 [x±√(d²−y²)]，按右端点贪心。
3. 提示：赢就赢；赢不了用最慢马换对方最快。
4. 提示：把大堆换成更小的堆，总代价不增。
5. 提示：让最短活动卡中间，挡住两个长的。

## E.9 第 9 章　递归：把大问题变小

1. 提示：`n==0` 返回 1，只写 `n==1` 会漏 0!。
2. 提示：偶数平方 a^(n/2)，奇数再乘 a，深度 `O(log n)`。
3. 提示：`dfs(已选, 个数)` 配 `used` 数组，选满输出。
4. 提示：由 2T(n−1)+1 归纳出 2^n−1，再按此构造。
5. 提示：改迭代 `O(n)`/`O(1)`，或加记忆化 `O(n)`。

## E.10 第 10 章　分治：分开算，再合并

1. 提示：双指针各指头，小者先放。
2. 提示：漏了右半收尾：`while (j<=r)` 还要接着搬。
3. 提示：顺序对+逆序对=n(n−1)/2，归并改判 `a[i]<a[j]`。
4. 提示：快选只往含 k 的一侧递归，期望 `O(n)`。
5. 提示：T(n)=T(n/2)+`O(1)`，故 `O(log n)`；奇数额外乘 a。

## E.11 第 11 章　深度优先搜索

1. 提示：只扩 `dx`、`dy` 成 8 方向，其余不动。
2. 提示：`dfs(start, 已选个数)`，下一个从 `start+1` 起。
3. 提示：每区试 4 色，与相邻冲突就换色。
4. 提示：深度可达 10^6，必爆栈；改 BFS。
5. 提示：状态=已填格与行列宫占用；回头清占用。
6. 提示：放一个数就判与前一数之和是否为质数。

## E.12 第 12 章　广度优先搜索

1. 提示：BFS 首次弹出 t 的层数即答案，队空输出 −1。
2. 提示：多源 BFS：出口先入队，一次算完。
3. 提示：出队才标记会重复入队，改入队即标记。
4. 提示：状态用 9 位串或康托，共 9! 种，要去重。
5. 提示：状态要加钥匙维度，一维会丢信息。
6. 提示：BFS 求最少步数；约 10^4 状态，转移 10×26。

## E.13 第 13 章　回溯与剪枝

1. 提示：在 `ans++` 处打印并 `return`，别再继续搜。
2. 提示：记左右括号数：右不超左，左不超 n。
3. 提示：排序后同层跳过相同的值（`i>start`）。
4. 提示：进格标记、退出撤销；最后才撤会漏解。
5. 提示：按性价比排序，用剩余容量的上界剪枝。
6. 提示：先填候选最少的格，分支少、冲突早现。

## E.14 第 14 章　栈、队列与单调结构

1. 提示：数字入栈；遇运算符弹 b、a 算 a op b。
2. 提示：计数器足够：左括号加，右括号减。
3. 提示：单调递增栈存下标，弹栈定左右边界。
4. 提示：队列改存递增，入队前弹更大队尾。
5. 提示：入栈时把主队列挪空再交换；pop 最坏 `O(n)`。

## E.15 第 15 章　哈希、集合与映射

1. 提示：先计数，再按原序找计数为 1 的数。
2. 提示：`set` 存已见数，对 x 查 target−x；`pair` 天然去重。
3. 提示：底数、模数太小都会撞；改用双哈希。
4. 提示：排序去重后 `lower_bound` 求排名，大小关系不变。
5. 提示：质数桶更匀；负载因子超 0.7 就扩桶。

## E.16 第 16 章　堆与优先队列

1. 提示：排序 `O(n log n)`；小根堆只留 k 个是 `O(n log k)`。
2. 提示：按截止时间排序，超时就弹掉最长的。
3. 提示：每次取最小丑数乘 2、3、5 入堆，`set` 去重。
4. 提示：偶数个取较小堆顶；左右邻则两堆不够。
5. 提示：push 上浮、pop 下沉；原地交换省空间。

## E.17 第 17 章　并查集

1. 提示：合并时维护 `sz`，最后数根数与最大 `sz`。
2. 提示：合并完得块数 c，还需修 c−1 条。
3. 提示：拆点：i 与 i+n 分别是朋友域、敌人域。
4. 提示：每加边不同根就合并、块数减一。
5. 提示：带权并查集，边权为前缀和之差。
6. 提示：`nxt[i]` 指下一空位，坐满跳后继，近 `O(α(n))`。

## E.18 第 18 章　树状数组与线段树

1. 提示：`add` 沿 `i+=lowbit`；区间和用两个前缀和相减。
2. 提示：差分：l 加 k、r+1 减 k，查 `a[x]` 即前缀和。
3. 提示：从右往左插入数更小者，值大先离散化。
4. 提示：`pushup` 取左右最大；最大值不可减，只能合并。
5. 提示：漏清 `lazy[o]=0`，下传后还要递归。
6. 提示：外层行、内层列各走 `lowbit`，查询分四块。

## E.19 第 19 章　图与图的遍历

1. 提示：每条边给两端度数加一，再取最大。
2. 提示：DFS 记父结点，遇已访问非父即有环。
3. 提示：染色冲突输出 `No`；否则按颜色分组。
4. 提示：BFS，`dist` 初 −1，首次到达即最短。
5. 提示：无向图漏 `push_back(v,u)`，`vis` 也没清。
6. 提示：倒着加点：先算删完的图，再逐个加回。

## E.20 第 20 章　最短路

1. 提示：堆优化 Dijkstra，弹出时 d>`dist[u]` 就跳过。
2. 提示：松弛成功记 `pre[v]=u`，从 n 回溯再反转。
3. 提示：扫 n 轮；第 n 轮仍松弛即有负环。
4. 提示：权 0 入队首、权 1 入队尾，双端队列 `O(n+m)`。
5. 提示：松弛时同步转移 `cnt`，相等累加。
6. 提示：堆按 `{dist,v}` 入队，弹出后判是否过期。

## E.21 第 21 章　最小生成树与拓扑排序

1. 提示：边按权排序加并查集，选满 n−1 条。
2. 提示：稠密图用邻接矩阵；稀疏图用邻接表加堆。
3. 提示：Kahn 每次取入度 0 的编号最小点。
4. 提示：Kahn 数入队个数；DFS 遇灰边即有环。
5. 提示：在拓扑序上做 `dp[v]+=dp[u]`，从 1 号点推。
6. 提示：求 MST 后枚举非树边换掉最大边。

## E.22 第 22 章　树上的算法

1. 提示：栈迭代求 `depth`，按出栈逆序累加 `size`。
2. 提示：后序求 `down1`、`down2`，答案取两者和最大。
3. 提示：倍增 `up[k][v]` 求 LCA，再套 `depth` 距离式。
4. 提示：点差分加一减二；边差分减量不同。
5. 提示：重心按最大子树最小求；换根 `sum[v]=sum[u]+n−2sz[v]`。

## E.23 第 23 章　从递归到动态规划

1. 提示：三项递推，`f[0]=1` 起；n≤70 要 `long long`。
2. 提示：比较左下右下记 `from`，再回溯输出。
3. 提示：状态是以 a[i] 结尾的最大和。
4. 提示：改 `<=` 后可重复接；要方案记 `pre`。
5. 提示：环拆成不偷 1、不偷 n 两个线性问题。
6. 提示：0 不能当未算标记，改 −1；base case 写 0、1。

## E.24 第 24 章　背包问题

1. 提示：体积当重量也当价值，做 0-1 背包。
2. 提示：完全背包正序枚举容量，`dp[0]=0`，末判 −1。
3. 提示：外层组、中层容量倒序、内层物品。
4. 提示：`dp[0]=0` 其余 −`INF`，末位为负即无解。
5. 提示：三维 `dp[i][w1][w2]`，滚动掉 i，两维倒序。
6. 提示：二维费用，两维都倒序枚举。

## E.25 第 25 章　区间 DP 与序列 DP

1. 提示：改取 max；贪心合最大两堆并不最优。
2. 提示：数组接长一倍，枚举长度 2..n 取 min。
3. 提示：从 (n,m) 倒推：相等走左上，否则走 dp 大的。
4. 提示：`s[l]==s[r]` 用 `dp[l+1][r−1]+2`，否则取两端最大。
5. 提示：初值取区间长度；能配对用 `dp[l+1][r−1]`。
6. 提示：LCS 外字符各删插一次，故 = |s|+|t|−2LCS。

## E.26 第 26 章　树形 DP 与状压 DP

1. 提示：强制选根，另一状态置 −`INF`，再回溯。
2. 提示：后序求 `down1`、`down2`，取和最大，注意负权。
3. 提示：加虚拟 0 号根，`dp[u][j]` 规定 u 必选再合并。
4. 提示：`dp[i][mask]` 记前 i 行列占用，与上行不交。
5. 提示：另开 `pre[mask][i]`，从终点倒着退回路线。

## E.27 第 27 章　DP 优化入门

1. 提示：一维滚动，j 正序才用得上新值。
2. 提示：用前缀和相减，减完加 MOD 再取模。
3. 提示：前缀和 P，求 `P[i]−min P[j]`（j 在窗口），单调队列。
4. 提示：分别用斜率/分治、常数递推、单调队列。
5. 提示：dp 展成点斜式，最优 j 随 i 右移；含负失效。

## E.28 第 28 章　字符串算法

1. 提示：`next` 是相等前后缀长；末尾 a 只配前缀 a。
2. 提示：暴力约 (n−m+1)m≈28 次；KMP 约 n+m 次。

5. 提示：底数模数已知就能造出碰撞串。
