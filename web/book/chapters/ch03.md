# 第 3 章　STL 速成

晚上七点，青云市集亮起一串串灯。两百多个摊位挤在几条巷子里，卖丝娃娃的、烤脑花的、烙锅的，油烟混着折耳根的香气。

老周递给小黔一张皱巴巴的纸，上面记着今晚要干的活：

"第一，把这些摊位的价格从低到高排一排，我要看看哪几家最便宜；第二，我报一个名字，你得马上告诉我它的价格；第三，同名的摊位有好几个，先去掉重复的，再看看第 k 便宜的是谁。"

小黔掏出本子就开始画数组和循环，写到第三页停住了："这得写到明天早上。"

老周笑了："这些活，标准库（Standard Template Library，STL）里都有现成的零件。数组有 `vector`，排序有 `sort`，查表有 `map`，去重有 `set`。会用工具箱的人，十分钟就干完了。"

这一章我们就把这个工具箱打开，认识最常用的七八个零件。原理留给后面的章节，这里先做到一件事：**知道什么活该拿哪个零件**。

> **本章学习目标**
> ① 用 `vector` 代替手写数组，用 `sort` 一行完成排序；
> ② 会写多关键字的比较函数，知道 `set`、`map` 什么时候比数组好用；
> ③ 认识 `stack`、`queue`、`priority_queue`，并记住迭代器失效这个坑。

## 3.1 vector：比数组好在哪里

`vector` 是能自动变长的数组，中文常叫动态数组（dynamic array）。普通数组开多大就得想清楚，`vector` 不用：元素装不下了，它自己申请一块更大的地方，把旧元素搬过去。

```cpp
#include <vector>

vector<int> a;            // 空数组
a.push_back(5);           // 尾部追加一个 5
a.push_back(7);           // 变成 {5, 7}
int n = (int)a.size();    // 现在有 2 个元素
a[0] = 9;                 // 当成普通数组用，下标从 0 开始
```

竞赛里最常见的两种声明方式：知道有多少个元素，就写 `vector<int> a(n);`，大小是 n，下标 `0` 到 `n-1`；想保留 1-indexed 的习惯，就写 `vector<int> a(n + 1);`，用 `a[1]` 到 `a[n]`。不知道有多少个元素，就声明空的，一边读一边 `push_back`。

`vector` 比数组多出来的能力，值得记下来：

- `size()` 随时知道有多少个元素，不用自己维护计数器；
- 可以直接赋值、可以当函数返回值，数组这两件事都做不到；
- `resize(m)` 改大小，`clear()` 清空，`back()` 看最后一个；
- 能嵌套：`vector<vector<int>> g(n + 1, vector<int>(m + 1, 0));` 就是一个 n 行 m 列的二维表，全部初始化为 0。

有一个坑必须现在就说：`size()` 返回的是无符号数（unsigned）。空数组的 `size() - 1` 不是 -1，而是一个巨大的正数。所以循环下标要写成 `for (int i = 0; i < (int)a.size(); i++)`，把 `size()` 先转成 `int` 再比较。

`vector` 也不是万能的。元素个数固定、只有几百个时，普通数组更直接、更快；`vector` 的优势在"大小事先不知道"和"需要一整套现成操作"。竞赛里两者混着用，没人会苛责你。

还有一个细节：`vector` 每次 `push_back` 发现容量不够时，会申请一块大约两倍大的新空间，把旧元素搬过去。单看某一次很贵，但把所有 `push_back` 平摊下来，平均每次只花常数时间，这叫均摊 `O(1)`，第 4 章会仔细算。如果你大概知道要装多少元素，可以先 `a.reserve(n)` 一次性把容量要够，省掉反复搬家。

`vector` 当函数参数时写 `const vector<int> &a`，加引用是为了不复制整个数组，加 `const` 是为了不许函数改它。`vector` 也能直接 `return`，这一点比数组强很多。

`vector` 的 `erase` 删除中间元素时，要把后面所有元素往前挪一位，是 `O(n)`；`push_back`、`pop_back` 只在尾部操作，才是 `O(1)`。需要频繁在中间插入、删除的场景，`vector` 并不合适，本书用不到，先知道有这回事。

访问元素时，`a[i]` 和普通数组一样不检查越界，速度最快；`a.at(i)` 会检查越界并抛异常，但竞赛里几乎不用——检查本身要花时间，而且真越界时程序已经来不及救了。越界的责任，永远在写代码的人身上。

## 3.2 sort 与自定义比较：多关键字排序

排序是算法题里出现频率最高的操作，而 C++ 把它压缩成了一行：

```cpp
#include <algorithm>

sort(a.begin(), a.end());                  // 升序
sort(a.begin(), a.end(), greater<int>());  // 降序，需要 #include <functional>
```

`sort` 的时间复杂度是 `O(n log n)`。这个数字意味着：一百万个元素，一眨眼就排完了。手写冒泡排序是 `O(n^2)`，同样的数据要跑很久（第 4 章会算这笔账）。

默认的 `sort` 用 `<` 比较。整数、字符串都能直接比，结构体不行——编译器不知道两个摊位谁该排前面。这时要给它一个比较函数：

```cpp
bool cmp(const Stall &a, const Stall &b) {
    if (a.price != b.price) return a.price < b.price;   // 先比价格
    return a.name < b.name;                             // 价格相同再比名字
}
```

比较函数只有一个要求：**回答"a 是不是严格排在 b 前面"**。相等的时候必须返回 `false`。这一点很容易写错：如果你写 `a.price <= b.price`，两个价格相同的摊位会互相"小于"，`sort` 的内部逻辑被搅乱，程序可能越界崩溃。这个错误不报编译错，只在某些数据上炸，查起来非常痛苦。

把 `cmp` 传给 `sort`：`sort(a.begin(), a.end(), cmp);`。多个关键字就按优先级一层层往下写，先判断最重要的，相等再判断下一个。

`sort` 不保证相等元素的原始顺序。如果题目要求"价格相同的摊位保持输入顺序"，用 `stable_sort`，用法完全一样。

`sort` 也能排普通数组，注意区间是左闭右开：`sort(a + 1, a + n + 1);` 排的是 `a[1]` 到 `a[n]`。习惯 1-indexed 的读者，这一行要记准。

想要降序，除了 `greater<int>()`，也可以自己写比较函数把小于号反过来。还有一种更省事的写法是匿名函数，等你看熟了再学：

```cpp
sort(a.begin(), a.end(), [](int x, int y) {
    return x > y;   // 大的排前面
});
```

比较函数的参数一定要用 `const` 引用。按值传参时，每次比较都要复制两个结构体。一百万个元素排序要比较两千万次，复制的时间能把程序拖慢一大截。

举个具体例子：给学生按成绩从高到低排，成绩相同按学号从小到大。比较函数先写 `if (a.score != b.score) return a.score > b.score;`，再写 `return a.id < b.id;`。两行代码，两个关键字，先后顺序就是优先级。

### 例题 3-1　青云市集摊位排序与统计（vector + sort + 多关键字）

**题目**：青云市集有 m 个摊位，给出摊位名称和单价。请按单价从低到高排序输出；单价相同时按名称的字典序排列。最后输出所有摊位的单价之和，以及"平价摊位"（单价不超过 20 元）的个数。

**输入格式**：第一行一个整数 m。接下来 m 行，每行一个不含空格的名称和一个整数单价。

**输出格式**：先输出 m 行排好序的"名称 单价"，再输出两行：`total 总价` 和 `cheap 个数`。

**样例 1**

输入：
```
6
丝娃娃 18
肠旺面 12
烤脑花 25
恋爱豆腐果 8
牛肉粉 13
酸汤鱼 68
```
输出：
```
恋爱豆腐果 8
肠旺面 12
牛肉粉 13
丝娃娃 18
烤脑花 25
酸汤鱼 68
total 144
cheap 4
```

**数据范围**：1 ≤ m ≤ 10^5，1 ≤ 单价 ≤ 10^4，名称不含空格且长度不超过 20。

**思路**：三件事：排序、求和、数个数。求和、数个数这两件事扫一遍就行，麻烦的是排序。

先用结构体把"名称 + 单价"绑在一起，再用 `vector` 装起来，大小是 m。比较函数按两个关键字写：价格不同比价格，价格相同比名字。

总价最大是 10^5 × 10^4 = 10^9，`int` 勉强装得下，但贴着上限，养成用 `long long` 的习惯。

**代码**：

```cpp:ch03_ex1.cpp
#include <iostream>
#include <algorithm>
#include <string>
#include <vector>
using namespace std;

struct Stall {
    string name;   // 摊位名
    int price;     // 单价
};

bool cmp(const Stall &a, const Stall &b) {
    if (a.price != b.price) return a.price < b.price;   // 第一关键字：价格
    return a.name < b.name;                             // 第二关键字：名称
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int m;
    cin >> m;
    vector<Stall> stalls(m);
    for (int i = 0; i < m; i++) {
        cin >> stalls[i].name >> stalls[i].price;
    }

    sort(stalls.begin(), stalls.end(), cmp);   // 一行完成多关键字排序

    long long total = 0;
    int cheap = 0;
    for (const auto &s : stalls) {
        cout << s.name << " " << s.price << "\n";
        total += s.price;
        if (s.price <= 20) cheap++;
    }
    cout << "total " << total << "\n";
    cout << "cheap " << cheap << "\n";
    return 0;
}
```

## 3.3 string：字符串的常用操作

`std::string` 是 C++ 的字符串（string）类型，比 `char` 数组省心得多：能拼接、能比较、能取子串、能查找。

```cpp
string s = "abc";
s += "def";                        // 拼接，s 变成 "abcdef"
int len = (int)s.size();           // 长度，6
char c = s[0];                     // 'a'，下标从 0 开始
if (s == "abcdef") { /* 可以整体比较 */ }
if (s.find("cde") != string::npos) { /* 找到了 */ }
string sub = s.substr(1, 3);       // 从下标 1 开始取 3 个字符："bcd"
```

`find` 找不到时返回 `string::npos`，这是一个特殊的无符号数，不要和 `-1` 混着用，判断就写 `!= string::npos`。

两个转换函数也很常用：`to_string(123)` 把整数变成字符串 `"123"`；`stoi("123")` 把字符串变回整数。`stoi` 遇到不是数字的字符会抛异常，竞赛题一般保证输入合法，但自己要记住这个前提。大整数用 `stoll`。

读入时注意区分：`cin >> s` 读到空格就停；`getline(cin, s)` 读一整行，空格保留。上一章那个 `cin.ignore()` 的坑，在这里同样存在。

还有一个容易忽略的点：`s.size()` 是字节数，不是"字数"。一个汉字在 UTF-8 里通常占 3 个字节，所以对中文名调用 `size()` 会得到 3 倍的数。竞赛题里的中文地名一般只做整体比较，不按下标拆开；真要处理字符，用英文题面更省事。字符串的深度算法放在第 28 章。

遍历字符串和遍历数组一样：

```cpp
for (char c : s) {
    if (c >= '0' && c <= '9') {
        int digit = c - '0';    // 字符 '7' 减 '0' 就得到数字 7
    }
}
```

字符在计算机里就是整数，`'0'` 到 `'9'` 是连续的，所以 `c - '0'` 能直接把数字字符变成对应的数值。这个技巧在处理读入的字符网格、解析时间格式时用得很多。大小写转换同理：`c - 'a' + 'A'` 能把小写变大写。

## 3.4 pair 与 tuple：把两个数绑在一起

有些数据天生成对：坐标 `(x, y)`、一条边的 `(终点, 边权)`、一个学生的 `(分数, 学号)`。`pair` 就是干这个的。

```cpp
#include <utility>

pair<int, int> p = {3, 5};
cout << p.first << " " << p.second << "\n";   // 3 5
p.first = 7;                                  // 可以单独改
auto q = make_pair(1, 2);                     // 另一种写法
```

`pair` 最妙的地方在排序：`vector<pair<int, int>>` 直接 `sort`，默认先比 `first`，`first` 相同再比 `second`。也就是说，很多"多关键字排序"用 `pair` 就能省掉比较函数。

```cpp
vector<pair<int, int>> v = {{2, 9}, {1, 5}, {2, 3}};
sort(v.begin(), v.end());   // 结果：(1,5) (2,3) (2,9)
```

需要绑三个以上的值，用 `tuple`：`tuple<int, int, string> t = {1, 2, "x"};`，取值用 `get<0>(t)`。`tuple` 用得少，见到认识就行。

`pair` 的比较规则和排序规则一致：先比 `first`，相等再比 `second`。所以 `pair` 天生就是"两个关键字"的排序工具，代价是不好读——`p.first`、`p.second` 用得多了，自己都会忘哪个是哪个。数据结构里存边、存坐标时，`pair` 是标配；讲解逻辑时，结构体更清楚。两种都备着，看场合用。

C++17 还给 `pair` 加了一个顺手的写法，叫结构化绑定（structured binding）：`auto [x, y] = p;`，一次把两个值拆成两个变量，之后直接用 `x`、`y`。本书的代码统一按 C++17 编译，这个写法可以放心用。

`pair` 在本书后面出现的频率很高：图的边（第 19 章）、坐标（第 12 章）、`map` 里的键值对（下一节），到处都是它。

## 3.5 set 与 map：自动排序 + 快速查找

老周说"我报一个名字，你马上告诉我价格"，这就是查找。用数组也能查，从头扫到尾是 `O(n)`；两百个摊位不算慢，但如果是两百万个呢？

集合（`set`）和映射（`map`）是专门为"查找"准备的容器，插入、删除、查找都是 `O(log n)`。`set` 存单个值，自动去重、自动升序；`map` 存"键 → 值"（key → value），按键自动升序。

```cpp
#include <set>
#include <map>

set<int> s;
s.insert(3);
s.insert(3);              // 重复插入无效，集合里只有一个 3
s.insert(1);
if (s.count(3)) { /* 3 在集合里 */ }
// 遍历 s：1 3，自动升序

map<string, int> price;
price["丝娃娃"] = 18;      // 直接赋值
if (price.count("肠旺面")) { /* 存在 */ }
auto it = price.find("丝娃娃");
if (it != price.end()) {
    cout << it->second << "\n";   // 18；it->first 是键
}
```

`map` 有一个暗坑：用 `m[key]` 访问一个不存在的键，它会自动插入一个默认值（`int` 就是 0）。所以"判断在不在"要用 `count()` 或 `find()`，不要用 `m[key]`。程序不崩，但你的 `map` 里会多出一堆假数据。

`set` 里的元素是只读的。想改一个值，只能先删掉再插入新的，因为它在容器里的位置由值决定，改了值就破坏了顺序。

`map` 遍历时是按 key 升序的，取键写 `kv.first`，取值写 `kv.second`。如果只需要"查得快"、不在乎顺序，可以用 `unordered_set`、`unordered_map`，平均 `O(1)`，第 15 章会讲它们什么时候会被卡。

`O(log n)` 是什么感觉？一百万个元素，`log2(10^6)` 约等于 20，也就是说查找一次最多比较 20 次，而不是一百万次。`set`、`map` 底层是平衡树，元素永远保持有序，代价是每次插入、删除都要调整结构。

`set` 还有一个好用的接口 `lower_bound(x)`：返回第一个大于等于 x 的位置，配合 `upper_bound` 可以查询某个范围内的元素个数（第 15 章展开）。`map` 的键必须能比较大小，`int`、`string` 都行；自己定义的结构体当键，就得给它一个比较函数。

`set` 也支持范围 `for` 遍历：`for (int x : s) cout << x << "\n";`，输出的顺序就是升序。`map` 统计词频是它最经典的用法：

```cpp
map<string, int> cnt;
cnt[name]++;   // 不存在时自动插入 0 再自增，正好是计数
```

注意 `cnt[name]++` 和前面说的"用 `m[key]` 判断存在性"是两回事。计数时，我们确实想让它插入；判断存在性时，我们不想。所以要分清楚场景。

如果允许重复元素，用 `multiset`，`count(x)` 能告诉你 x 出现了几次。比赛里遇到"去重"用 `set`，遇到"保留重复"用 `multiset`，别混。

### 例题 3-2　地铁站名索引（map 的查找）

**题目**：贵阳地铁有 n 个站点，每个站点属于一条线路（练习题里先这样简化：换乘站也只记一条线）。接下来有 q 次查询，每次给一个站名，输出它所属的线路号；查不到输出 `NO`。

**输入格式**：第一行一个整数 n。接下来 n 行，每行一个不含空格的站名和一个整数线路号。然后一行一个整数 q。接下来 q 行，每行一个站名。

**输出格式**：q 行，每行一个整数或 `NO`。

**样例 1**

输入：
```
5
喷水池 1
贵阳北站 1
北京路 1
林城西路 2
龙洞堡机场 2
3
贵阳北站
林城西路
甲秀楼
```
输出：
```
1
2
NO
```

**数据范围**：1 ≤ n, q ≤ 10^5，站名长度不超过 20。

**思路**：用 `map<string, int>` 把站名映射到线路号。读入 n 个站名时直接 `lineOf[name] = line;`。查询时用 `find`，找到了输出 `it->second`，没找到输出 `NO`。

（样例里的站名和线路号是演示用的简化数据，不保证与真实线路一致，真实线路以运营方公布为准。）

如果用两层循环暴力查找，n 和 q 都到 10^5 时是 10^10 次比较，必超时。`map` 每次查询 `O(log n)`，总共约 10^5 × 17 次比较，轻松通过。

**代码**：

```cpp:ch03_ex2.cpp
#include <iostream>
#include <map>
#include <string>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;
    map<string, int> lineOf;          // 站名 -> 线路号
    for (int i = 1; i <= n; i++) {
        string name;
        int line;
        cin >> name >> line;
        lineOf[name] = line;
    }

    int q;

        if (it != lineOf.end()) {
            cout << it->second << "\n";
        } else {
            cout << "NO\n";
        }
    }
    return 0;
}
```

## 3.6 stack、queue、priority_queue：先会用，原理后面讲

这三个是"容器适配器"，用起来简单，但背后各有一套规则。

`stack` 是栈（stack），后进先出。像青云市集小吃摊上摞起来的碗，后来的碗摞在最上面，先拿走。

```cpp
#include <stack>

stack<int> st;
st.push(1);
st.push(2);
int top = st.top();   // 2，只看最上面
st.pop();             // 弹出 2，pop() 不返回被弹出的值
```

`queue` 是队列（queue），先进先出。像青云市集门口早高峰排队，先来的先过去。

```cpp
#include <queue>

queue<int> q;
q.push(1);
q.push(2);
int front = q.front();   // 1
q.pop();                 // 弹出 1
```

`priority_queue` 是优先队列（priority queue），每次取出的都是当前最大的元素，内部用堆实现，插入和删除都是 `O(log n)`。

```cpp
priority_queue<int> pq;                 // 默认大根堆，top() 是最大值
pq.push(3);
pq.push(9);
cout << pq.top() << "\n";               // 9

priority_queue<int, vector<int>, greater<int>> small;   // 小根堆
```

三个容器的 `pop()` 都只负责删除，不返回被删的元素，所以要先 `top()` 再 `pop()`，顺序反了就拿不到值了。对空容器调用 `top()`、`front()` 是未定义行为，用之前先 `empty()` 判一下。

它们的共同点是只暴露"该暴露的那一面"：栈只能碰顶部，队列只能碰两头，优先队列只能碰最大（或最小）的那个。正是这种限制，让它们的操作都能做到 `O(1)` 或 `O(log n)`。

优先队列最常用的场景是"数据一直在进来，我要随时知道最大的几个"。求第 k 大，通常维护一个大小为 k 的小根堆：新元素比堆顶大就替换，最后堆顶就是第 k 大。这个套路第 16 章会拿完整例子走一遍。

它们什么时候出场：括号匹配、表达式求值用 `stack`（第 14 章）；BFS 找最短路用 `queue`（第 12 章）；Top-K、合并果子用 `priority_queue`（第 16 章）。现在只要记住名字和"后进先出 / 先进先出 / 每次取最大"这三句话就够。

## 3.7 迭代器失效与容器选择

迭代器（iterator）可以理解成"指向容器里某个元素的指针"，`begin()` 指第一个，`end()` 指最后一个的后面一个。`sort`、`find` 这些函数都靠它工作。

问题出在"一边遍历一边改容器"的时候。`vector` 扩容会把所有元素搬到新地址，之前保存的迭代器、指针、引用全部失效，再用就是访问野内存。`erase` 也一样：删除位置之后的迭代器都失效了。说白了，就是容器内部一搬家，原来那个"指针"指的位置已经不是你想的那个元素了。

错误写法：

```cpp
for (int x : v) {
    if (x % 2 == 0) v.erase(find(v.begin(), v.end(), x));   // 迭代器已失效
}
```

正确写法是让 `erase` 返回下一个有效位置：

```cpp
for (auto it = v.begin(); it != v.end(); ) {
    if (*it % 2 == 0) it = v.erase(it);   // erase 返回下一个元素的位置
    else ++it;
}
```

记住两条：不要在范围 `for` 里 `push_back`；删除元素时用上面这种 `it = erase(it)` 的写法。

不同容器的失效规则不一样。`vector` 最"娇气"：扩容会让所有迭代器作废，删一个元素会让它后面的全部作废。`map`、`set` 温和得多：删掉一个元素，只有指向它的迭代器失效，别的还能用。这就是"连续内存"和"树形结构"的差别，等第 15 章讲完底层就完全明白了。

![图 3-1　STL 容器选择决策树](assets/fig-03-stl.png)

最后是这张选型表。写题时先想清楚"我要什么操作"，再查表：

| 我要干什么 | 用什么 | 单次操作复杂度 |
|---|---|---|
| 按顺序存一堆数，大小不定 | `vector` | 访问 `O(1)`，尾部插入均摊 `O(1)` |
| 排序、按关键字排序 | `sort` + 比较函数 | `O(n log n)` |
| 去重并保持有序 | `set` | `O(log n)` |
| 按键快速查值 | `map` | `O(log n)` |
| 后进先出 | `stack` | `O(1)` |
| 先进先出 | `queue` | `O(1)` |
| 每次取最大/最小 | `priority_queue` | `O(log n)` |
| 只查不管顺序（第 15 章） | `unordered_map` | 平均 `O(1)` |

这张表不用背，用几次就记住了。选容器的顺序是：先列操作，再看每种操作要几次，最后挑总代价最小的。别为了"显得会用 STL"硬套容器——有时候一个普通数组加两层循环，比绕一大圈还清楚。算法题里，能跑对、跑得够快，比写法花哨重要得多。

### 例题 3-3　去重与第 k 小（sort + unique + erase）

**题目**：给 n 个整数，先去重，再求第 k 小的数。如果去重后的个数不足 k，输出 `NO`。

**输入格式**：第一行两个整数 n 和 k。第二行 n 个整数。

**输出格式**：一个整数，或 `NO`。

**样例 1**

输入：
```
6 3
5 2 5 1 2 8
```
输出：
```
5
```

**数据范围**：1 ≤ n ≤ 10^5，1 ≤ k ≤ n，|a[i]| ≤ 10^9。

**思路**：排序之后，重复的元素一定挨在一起。`unique` 把相邻的重复元素"挪到后面"，返回去重后新末尾的位置；`erase` 把后面那一段真正删掉。这两行是固定搭配，背下来：

```cpp
sort(a.begin(), a.end());
a.erase(unique(a.begin(), a.end()), a.end());
```

去重后数组升序，第 k 小就在下标 `k-1` 处（`vector` 从 0 开始）。先判断 `k` 有没有超过去重后的元素个数。

**代码**：

```cpp:ch03_ex3.cpp
#include <iostream>
#include <algorithm>
#include <vector>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, k;
    cin >> n >> k;

    vector<int> a(n);
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }

    sort(a.begin(), a.end());                            // 1. 排序
    a.erase(unique(a.begin(), a.end()), a.end());        // 2. 去重

    if (k >= 1 && k <= (int)a.size()) {
        cout << a[k - 1] << "\n";       // 第 k 小在 0-indexed 的 k-1 处
    } else {
        cout << "NO\n";
    }
    return 0;
}
```

**易错点**：`unique` 之后忘了 `erase`；下标用 `k` 而不是 `k-1`；`k` 的范围没检查，空数组访问越界。

## 本章小结

> **记住这三句**
> ① `vector` 当数组用，`sort` 一行排序，比较函数记住"相等返回 `false`"；
> ② 要"自动有序 + 快速查找"就用 `set`、`map`，单次操作 `O(log n)`；
> ③ 容器扩容或删除元素之后，旧的迭代器不要再碰。
