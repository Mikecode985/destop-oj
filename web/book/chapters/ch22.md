# 第 22 章　树上的算法

傍晚七点，观山湖区一个建在山坡上的老小区。这里是贵阳的新城区，路修得宽，坡也多，小区就顺着坡一层层往上盖。老周把电瓶车停在大门口，抬头看那一栋栋顺着坡排上去的楼，叹了口气。今天有十几个件要送，散落在十来栋楼里。

这小区有点特别：从大门进去是一条主路，主路在半坡分成两条，其中一条又分成三条……路和路之间没有绕回去的道。你从任何一栋楼走到另一栋楼，路线只有一条，想走第二条都没有。

这样的路网在贵阳不算稀奇。山城的地形摆在那儿，老小区多是"一条主路分岔、岔了再岔"，很少修成环线——坡上绕一圈回来，费地又费钱。

"这路网干净得像棵树。"老周说。

他说对了。**连通、没有环**的路网，在算法里就叫**树（tree）**。树是最简单的一种图，也是竞赛里出现得最多的一种图。正因为它简单，很多看起来麻烦的问题反而有漂亮的解法：

- 从快递站出发，最远要骑到哪栋楼？——这是**树的直径（diameter）**。
- 两个快递员分头往上走，最近在哪个岔路口碰头？——这是**最近公共祖先（lowest common ancestor，LCA）**。
- 十几条配送路线，每一段路各被走了几次？——这是**树上差分（difference on tree）**。
- 快递柜放哪栋楼，大家下楼取件的总路程最短？——这跟树的**重心（centroid）**有关。

老周这片小区离**贵阳北站**不远，一半的件是从北站那头的仓库拉过来的。所以"从大门到最里面那栋楼怎么走最近"，他每天都要在脑子里过一遍。

这一章把这几个问题一次讲完。你会发现，树上算法的代码都不长，难点全在"先把这棵树的形状想清楚"。

> **本章学习目标**
> ① 会用邻接表存树，会算深度、父亲与子树大小；
> ② 会求树的直径，会写倍增 LCA 回答"两点最近公共祖先"；
> ③ 能看懂树上差分与树形 DP 的套路，知道重心在哪、换根 DP 要解决什么。

## 22.1 树的性质与遍历：先给树"安一个根"

一棵树要满足三个条件：n 个结点、n-1 条边、连通且无环。其实只要满足其中两条，第三条就自动成立。

- n 个点、n-1 条边、连通：一定无环，否则边数会更多；
- n 个点、连通、无环：边数一定是 n-1；
- n 个点、n-1 条边、无环：一定连通，否则有一块是孤岛，边就不够用了。

所以竞赛里判断"这是不是一棵树"，最常用的办法是数边：读入 n-1 条边之后，做一次遍历看能不能走到所有点。第 19 章的图的遍历直接搬过来用就行。

树上的术语，拿小区对号最省事：

| 术语 | 意思 | 小区里对应 |
|---|---|---|
| 根（root） | 我们自己指定的那个起点 | 大门口 |
| 父亲（parent） | 从根往下走时，u 的上一层点 | 上一层的路口 |
| 儿子（child） | 父亲往下连的点 | 下一层的路口 |
| 叶子（leaf） | 没有儿子的点 | 路的尽头那栋楼 |
| 深度（depth） | 根到 u 经过的边数 | 从大门走几步到 |
| 子树（subtree） | u 和它所有后代的集合 | 从 u 往里能到的所有楼 |

"根"是我们自己挑的，这是理解树上算法的第一个关键：**树本身没有上下之分，是我们按了根之后才有了上下**。同一棵树，根选 1 号点时，b 是 a 的儿子；根选 b 时，a 又成了 b 的儿子。后面讲的深度、子树、LCA，全都依赖"根是谁"，所以读题第一件事是看清根是哪个点。题目没说，一般就默认 1 号点。

存树用邻接表，跟存图一模一样：

```cpp
const int MAXN = 100005;
vector<int> g[MAXN];
// 读一条边 u-v
g[u].push_back(v);
g[v].push_back(u);   // 无向树，两个方向都要存
```

遍历也能照搬第 19 章。不过树有一个特别好的性质：**从 u 走到儿子 v 之后，v 唯一的回头路就是 u**。所以树上遍历不必开 `vis` 数组，记住"我从父亲来"就够了：

```cpp
// 从 u 往下搜，fa 是 u 的父亲；返回以 u 为根的子树大小
int dfsSize(int u, int fa) {
    int s = 1;                          // 先把自己算上
    for (int v : g[u]) {
        if (v == fa) continue;          // 不走回头路，树里没有别的环
        s += dfsSize(v, u);             // 儿子算完再加进来
    }
    return s;
}
```

这段代码只有九行，但它是后面所有树形算法的骨架。注意 `int s = 1;` 那一行：**子树大小一定要把自己算进去**，新手最容易漏掉这里的 1。

但递归有个坑：递归深度等于树的高度。如果树退化成一条链（1-2-3-…-100000），深度就是 10 万，调用栈会被撑爆，直接 RE。所以 10^5 级别的树，本书一律用队列手动模拟：

```cpp
// 从根 1 出发 BFS，算出父亲和深度，order 里存访问顺序
int cnt = 0;
order[++cnt] = 1;
fa[1] = 0;
for (int head = 1; head <= cnt; head++) {   // 用 order 本身当队列
    int u = order[head];
    for (int v : g[u]) {
        if (v != fa[u]) {                   // 只往儿子方向走
            fa[v] = u;
            depth[v] = depth[u] + 1;
            order[++cnt] = v;
        }
    }
}
```

这里有个小技巧：`order` 数组既存访问顺序，又当队列用，`head` 是队头，`cnt` 是队尾。BFS 结束时，`order[1..n]` 是一个"父亲一定排在儿子前面"的顺序。

这个顺序很值钱。**把它倒过来扫，就得到"儿子一定排在父亲前面"的顺序**，也就是合法的后序。树形 DP 全靠它：轮到 u 的时候，它的儿子全都算完了。后面的例题会反复用到这一招。

这一节记三句话：树是连通无环的 n 点 n-1 边图；上下关系都是按根按出来的；树上算法的通用顺序是"BFS 拿 `order`，倒着扫"。

## 22.2 树的直径：小区里最远的两栋楼

老周想算一件事：从快递站出发，最远要骑多远？换成树的语言：**树上最远的两个点之间隔了几条边**，这个距离叫树的**直径**。

说白了，直径就是"这棵树上最远的两点相距多远"。放到小区里，就是"从门口到最里面那栋楼，最多要走几段路"。

最笨的办法是枚举所有点对 (u, v)，每对从 u 走一遍树算距离，取最大值。n 个点有 n(n-1)/2 对，每对 `O(n)`，总复杂度 `O(n^3)`。n 到 1000 就顶不住了。

好一点的办法要从一个观察出发：**从任意一个点出发，找到离它最远的点 a，那么 a 一定是某条直径的端点。** 这句话严格的证明要用反证法，这里只要记住结论，它带来一个极简单的算法：

1. 从任意点出发（一般选 1 号点），找到离它最远的点 a；
2. 从 a 出发，再找一次最远点 b；
3. a 到 b 的距离就是直径。

两趟遍历，每趟 `O(n)`，总共 `O(n)`。这就是"**两次 DFS**"——其实用 BFS 或手写栈都行，因为无权树上距离就是边数，谁来遍历都可以。

为什么这样就对？一句话直觉：第一趟已经把"最偏"的那一头挑出来了；从这一头再往最远处走，走到的只能是另一头。要是从 a 出发还能找到一个更远的点 c，那 a 就不是端点，矛盾。

### 例题 22-1　小区里最远的两栋楼（树的直径）

**题目**：给定一棵 n 个结点的无向树，边权都是 1，求树的直径（最远两点间的边数）。

**输入格式**：第一行一个整数 n。接下来 n-1 行，每行两个整数 u、v，表示 u 和 v 之间有一条边。

**输出格式**：一个整数，表示直径。

**样例 1**

输入：
```
5
1 2
2 3
3 4
4 5
```
输出：
```
4
```

**数据范围**：1 ≤ n ≤ 10^5。

**思路**：先写一个函数 `farthestFrom(start)`：从 start 出发遍历一遍，返回距离最远的结点编号，同时把每个点到 start 的距离写进全局数组 `dist`。第一趟从 1 号点出发得到端点 a，第二趟从 a 出发得到端点 b，此时 `dist[b]` 就是答案。

遍历用显式栈，不用递归，深度再大也不怕。`dist` 用 -1 表示"没访问过"，这样既起到 `vis` 的作用，又顺便存了距离。

**代码**：

```cpp:ch22_ex1.cpp
#include <iostream>
#include <vector>
using namespace std;

const int MAXN = 100005;
vector<int> g[MAXN];      // 邻接表：g[u] 里是 u 的所有邻居
int dist[MAXN];           // dist[i] 是从起点到 i 的边数，-1 表示没走到

// 从 start 出发遍历整棵树，返回离 start 最远的结点编号
int farthestFrom(int start, int n) {
    for (int i = 1; i <= n; i++) dist[i] = -1;   // 每趟都要清零，别用上一趟的旧值
    vector<int> stk;
    stk.push_back(start);
    dist[start] = 0;
    int best = start;                             // 目前最远的点
    while (!stk.empty()) {
        int u = stk.back();
        stk.pop_back();
        if (dist[u] > dist[best]) best = u;       // 边扫边更新最远点
        for (int v : g[u]) {
            if (dist[v] == -1) {                  // 没访问过才走，等价于不看父亲
                dist[v] = dist[u] + 1;
                stk.push_back(v);
            }
        }
    }
    return best;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;
    for (int i = 1; i < n; i++) {
        int u, v;
        cin >> u >> v;
        g[u].push_back(v);
        g[v].push_back(u);
    }
    int a = farthestFrom(1, n);      // 第一趟：从任意点找到直径的一端
    int b = farthestFrom(a, n);      // 第二趟：从这一端找到另一端
    cout << dist[b] << "\n";         // 第二趟后 dist 存的是到 a 的距离
    return 0;
}
```

1 4

**复杂度**：时间 `O(n)`，空间 `O(n)`。

**易错点**：只跑一趟就输出，得到的是"从 1 号点出发的最远距离"，那不是直径；`dist` 数组忘了重置，第二趟读到上一趟的旧值；n = 1 时要输出 0，一上来就返回 `start` 正好对上。

**带权怎么办？** 如果边上有长度（小区的路有多少米），两次遍历仍然成立，把 `dist[v] = dist[u] + 1` 换成 `dist[v] = dist[u] + w` 就行，前提是边权非负。

如果不能跑两趟（比如只允许扫一遍），可以用**树形 DP**：对每个点 u 记 `down1[u]` 为"从 u 往子树里走能到的最远距离"，`down2[u]` 为第二远。答案取所有点 `down1[u] + down2[u]` 的最大值——最长路径一定在某个点"拐一次弯"，两条链从它分出去。这个写法是下一节 LCA 之后、树形 DP 之前最自然的热身。

## 22.3 最近公共祖先：两个快递员在哪碰头

两个快递员，一个在 8 号楼，一个在 11 号楼，都要往小区门口走。他们在电话里对位置："你在哪个岔路口？"最后他们会走到同一个路口，而且从那个路口往上的路线完全一样。这个"最近的共同祖先"就是**最近公共祖先（LCA）**：u 和 v 的所有公共祖先里，深度最大的那一个。

注意"最近"两个字：根永远是公共祖先，但一般不是最近的。

**暴力怎么做？** 分两步。第一步，让深的那个人先往上走，直到两人深度一样；第二步，两人一起往上走，一步一比较，第一次走到同一个点就是 LCA。

第一步最多走 n 步，第二步也最多 n 步，一次询问 `O(n)`。q 次询问就是 `O(nq)`：n、q 都是 10^5 时是 10^10 次运算，稳稳超时。

**卡在哪？** 卡在"一步一步往上挪"。我们想一次跳好多步，但又不能跳过 LCA。

这里用**倍增（binary lifting）**：预处理一张跳表 `up[k][u]`，表示"从 u 往上跳 2^k 步落在哪个点"。k = 0 时是父亲，k = 1 时是父亲的父亲，k = 2 时是往上第 4 个……递推只有一行：

`up[k][u] = up[k-1][ up[k-1][u] ]`

意思是"跳 2^k 步 = 先跳 2^(k-1) 步，再跳 2^(k-1) 步"，跟快速幂拆指数是一个想法：任何整数都能拆成若干个 2 的幂相加。

用白话讲，**倍增就是"一次跨 2 的幂级台阶"**：想往上走 13 步，不必走 13 次，走 8 步、再走 4 步、再走 1 步就到了。跳表就是提前把"跨 1 步、2 步、4 步、8 步……会落在哪"都记下来，用的时候直接查。

![图 22-1　倍增 LCA 的跳表](assets/fig-22-lca.png)

图里画的就是这个递推：`up[2][u]` 指向 `up[1][ up[1][u] ]`。表只有 log n 行、每行 n 个格子，所以预处理 `O(n log n)`，空间也是 `O(n log n)`。

询问同样分两步，只是"走"改成了"跳"：

1. 把深的点跳到和浅的一样深。深度差写成二进制，哪一位是 1 就跳哪一行，`O(log n)` 步跳完。
2. 两人一起往上跳：从大到小试 k。如果 `up[k][a] != up[k][b]`，说明跳 2^k 步还不会碰头，就跳过去；如果相等，说明跳过去要么撞上、要么跳过头了，这一步不走。循环结束时两人一定停在 LCA 的两个不同儿子上，答案就是 `up[0][a]`。

### 例题 22-2　两个快递员碰头（倍增 LCA）

**题目**：给定一棵以 1 为根的树，q 次询问，每次给两个点 u、v，输出它们的最近公共祖先。

**输入格式**：第一行两个整数 n、q。接下来 n-1 行，每行两个整数 u、v，表示一条边。接下来 q 行，每行两个整数 u、v，表示一次询问。

**输出格式**：q 行，每行一个整数，表示该次询问的答案。

**样例 1**

输入：
```
5 3
1 2
1 3
2 4
2 5
4 5
3 4
1 5
```
输出：
```
2
1
1
```

**数据范围**：1 ≤ n, q ≤ 10^5。

**思路**：先用一次 BFS 求每个点的父亲 `up[0][u]` 和深度 `depth[u]`，再按 `up[k][u] = up[k-1][up[k-1][u]]` 把整张表填出来。注意"往上跳出树根"时落在 0 号点，0 号点的所有表项都是 0，这样越界问题自然消失，不用特判。

询问照上面的两步走。`LOG` 取 17 是因为 `2^17 = 131072 > 10^5`；写 20 更保险，多占一点空间而已。

**代码**：

```cpp:ch22_ex2.cpp
#include <iostream>
#include <vector>
#include <queue>
using namespace std;

const int MAXN = 100005;
const int LOG = 17;            // 2^17 = 131072 > 10^5，够跳完任何深度

vector<int> g[MAXN];
int depth[MAXN];               // 根到该点的边数，根自己为 0
int up[LOG][MAXN];             // up[k][v]：从 v 往上跳 2^k 步落到的点

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, q;
    cin >> n >> q;
    for (int i = 1; i < n; i++) {
        int u, v;
        cin >> u >> v;
        g[u].push_back(v);
        g[v].push_back(u);
    }

    // 第一层：BFS 从根 1 出发，算出每个点的深度和父亲
    vector<bool> vis(n + 1, false);
    queue<int> que;
    vis[1] = true;
    up[0][1] = 0;              // 根没有父亲，记 0 号点
    que.push(1);
    while (!que.empty()) {
        int u = que.front();
        que.pop();
        for (int v : g[u]) {
            if (!vis[v]) {
                vis[v] = true;
                depth[v] = depth[u] + 1;
                up[0][v] = u;
                que.push(v);
            }
        }
    }

    // 第二层：跳 2^k 步 = 先跳 2^(k-1) 步再跳 2^(k-1) 步
    for (int k = 1; k < LOG; k++)
        for (int v = 1; v <= n; v++)
            up[k][v] = up[k - 1][up[k - 1][v]];

    while (q--) {
        int a, b;
        cin >> a >> b;
        if (depth[a] < depth[b]) swap(a, b);       // 让 a 是更深的那一个
        int diff = depth[a] - depth[b];
        for (int k = 0; k < LOG; k++)
            if (diff >> k & 1) a = up[k][a];       // 按二进制位跳，把深度差抹平
        if (a == b) { cout << a << "\n"; continue; }   // 浅的那个就是祖先
        for (int k = LOG - 1; k >= 0; k--)
            if (up[k][a] != up[k][b]) {            // 没撞上就先跳过去
                a = up[k][a];
                b = up[k][b];
            }
        cout << up[0][a] << "\n";                  // 停在了 LCA 的两个儿子上
    }
    return 0;
}
```

**复杂度**：预处理 `O(n log n)`，每次询问 `O(log n)`，空间 `O(n log n)`。

**易错点**：`LOG` 开太小时，跳到一半就跳不动了；第二步结束后输出 `a` 而不是 `up[0][a]`；第一步跳完发现 a 已经等于 b，这时要直接输出，不能再进第二步（否则会跳到 0 号点上去）。

## 22.4 树上差分：一段路被走了几次

老周有十几个件，每个件从大门口送到某一栋楼。他想知道：**最忙的那段路，一天被走了几次？**

把问题说清楚：树上有 m 条路径，每条路径是"从 u 到 v"，路径上的每条边都算被经过一次，问最后每条边被经过的总次数。一条一条加的话，m 条路径、每条最多 n 条边，总复杂度 `O(nm)`，太大。

还记得第 18 章的差分吗？数组上做"区间加、最后求前缀和"，只要在区间左端点 +1、右端点的后一位 -1。树上能不能照搬？能，只是"区间"变成了"路径"，而树上的"前缀和"变成了**子树求和**。

**点差分**（统计每个点被经过几次）。设 w = LCA(u, v)，p 是 w 的父亲，四步：

- `diff[u] += 1`
- `diff[v] += 1`
- `diff[w] -= 1`
- `diff[p] -= 1`

然后从下往上，把每个点的 `diff` 加到它父亲身上（一次倒序扫描）。每个点最后的值，就是它被覆盖的次数。

**边差分**（统计每条边被经过几次）。把"边"记在它下面那个点上，公式只剩三行：`diff[u] += 1`、`diff[v] += 1`、`diff[w] -= 2`。重跑一遍子树求和，`diff[x]` 就是 x 到它父亲那条边的经过次数。

```cpp
// 点差分：一条 u-v 的路径，w 是 lca，p 是 w 的父亲
diff[u]++; diff[v]++; diff[w]--; diff[p]--;
// 后序累加：倒着扫 order，把儿子的值加给父亲
for (int i = n; i >= 1; i--) diff[fa[order[i]]] += diff[order[i]];
```

为什么这样是对的？一句直觉：u 和 v 各贡献了一条"从自己一直到根"的链；这两条链从 w 往上的部分是重合的，被加了两次，所以要减掉一次；再从 w 的父亲开始减一次，最后剩下的正好是 u 到 v 这一段。

为什么"子树求和"能当"前缀和"用？因为一个点的子树在 DFS 序里是连成一片的，**子树求和就是把"以 x 为根的那一整块"加起来**，正好对应"x 下面所有路径贡献的累加"。

**复杂度**：预处理 LCA 用 `O(n log n)`，每次修改 `O(log n)`，最后一遍求和 `O(n)`；m 次操作总共 `O((n + m) log n)`。比暴力快一个量级。

## 22.5 树形 DP 入门：相邻两栋楼不能都选

场景收回来。小区要在楼栋里装快递柜，有两个限制：有路直接相连的两栋楼不能都装（送件路线会重复），又希望装得越多越好。问最多装几个。

这类"每个点选或不选、选了邻居就不能选"的问题，在树上叫**最大独立集**。它还有个更出名的名字："没有上司的舞会"。公司里每个人都有一个上司，选了上司就不能选他的直接下属，问最多能选多少人。

**第一步：定状态。** 树形 DP 的状态几乎都长这个样子：`dp[u][0]` 和 `dp[u][1]`，意思是"只看以 u 为根的这棵子树，u 不选 / u 选"时的最优值。

**第二步：写转移。** 分两种情况，一看就懂：

- 如果 u 选了，它的每个儿子都不能选：`dp[u][1] = 1 + sum(dp[v][0])`；
- 如果 u 没选，儿子选不选都行，取大的：`dp[u][0] = 0 + sum(max(dp[v][0], dp[v][1]))`。

**第三步：定边界。** 叶子没有儿子，求和部分是空的，所以 `dp[叶子][0] = 0`、`dp[叶子][1] = 1`。写代码时不用特意判叶子，循环一次都不执行，天然就是这两个值。

**第四步：排顺序。** 这就是 22.1 那个 `order` 数组的用处：从后往前扫，轮到 u 时它的儿子全算好了。不用递归，链状树也不会爆栈。

答案是 `max(dp[1][0], dp[1][1])`。

**为什么状态只要两个？** 因为"u 选不选"对儿子的唯一影响，就是"儿子还能不能选"。父子之间就只有这一条信息，所以两个状态够用。这是树形 DP 的通用思路：**状态里只放"子树外面需要知道的信息"，多余的坚决不放**。

### 例题 22-3　相邻两栋楼不能都装（树上最大独立集）

**题目**：给定一棵 n 个结点的树，选出尽量多的结点，要求任意两个被选中的结点之间没有边直接相连，输出最多能选几个。

**输入格式**：第一行一个整数 n。接下来 n-1 行，每行两个整数 u、v，表示一条边。

**输出格式**：一个整数，表示最多能选的结点数。

**样例 1**

输入：
```
3
1 2
2 3
```
输出：
```
2
```

**数据范围**：1 ≤ n ≤ 10^5。

**思路**：以 1 为根，BFS 求出每个点的父亲 `fa` 和访问顺序 `order`，然后倒着扫 `order` 做后序 DP。转移就是上面那两行，注意 `dp1[u]` 要先把"自己"这 1 算上，再累加儿子。

**代码**：

```cpp:ch22_ex3.cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

const int MAXN = 100005;
vector<int> g[MAXN];
int fa[MAXN];                 // 每个点的父亲
int order[MAXN];              // BFS 访问顺序，倒着扫就是后序
int dp0[MAXN], dp1[MAXN];     // dp0[u]：u 不选；dp1[u]：u 选

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;
    for (int i = 1; i < n; i++) {
        int u, v;
        cin >> u >> v;
        g[u].push_back(v);
        g[v].push_back(u);
    }

    // BFS 一次：拿到父亲数组和一个"父亲在前、儿子在后"的顺序
    int cnt = 0;
    order[++cnt] = 1;
    fa[1] = 0;
    for (int head = 1; head <= cnt; head++) {
        int u = order[head];
        for (int v : g[u]) {
            if (v != fa[u]) {         // 树里不走回头路
                fa[v] = u;
                order[++cnt] = v;
            }
        }
    }

    // 倒着扫：轮到 u 时，它的儿子一定都算完了
    for (int i = n; i >= 1; i--) {
        int u = order[i];
        dp1[u] = 1;                   // u 选了，先把自己记上
        dp0[u] = 0;
        for (int v : g[u]) {
            if (v == fa[u]) continue; // 只看儿子，跳过父亲
            dp1[u] += dp0[v];         // u 选了，儿子只能不选
            dp0[u] += max(dp0[v], dp1[v]);   // u 不选，儿子随意
        }
    }
    cout << max(dp0[1], dp1[1]) << "\n";
    return 0;
}
```

**复杂度**：时间 `O(n)`，空间 `O(n)`。

**易错点**：`dp1[u] = 1` 这行要放在累加儿子之前，否则自己的 1 会被覆盖；遍历儿子时要 `if (v == fa[u]) continue;`，不然父亲会被当成儿子算进去；只有一棵树时答案取根的两种状态的最大值，不是只取 `dp1[1]`。

## 22.6 重心与换根：快递柜放在哪栋楼

最后回答老周最关心的那个问题：快递柜放哪栋楼，大家下楼取件的总路程最短？

严格的说法叫**重心（centroid）**：删掉这个点以后，剩下的每个连通块大小都不超过 n/2。直观上它就在树的"正中间"，从它出发到最远点最近。

说白了，重心就是那个"把它拿掉以后，剩下的每一块都不算大"的点。放到小区里：快递柜放在重心那栋楼，谁下楼取件都不会走太远。

求法只要一次后序遍历。先用 22.1 的办法求出每个点的子树大小 `size[u]`，再对每个 u 算一个"最坏情况"：

`worst[u] = max(n - size[u], 所有儿子的 size[v])`

`n - size[u]` 是 u 上面那一大块，儿子的 `size` 是下面每一块。取这些块里最大的那块，`worst[u]` 最小的那个 u 就是重心。复杂度 `O(n)`。

有个好用的性质：**重心一定在直径上**，而且一棵树最多有两个重心，它们一定相邻。所以"求直径"和"找重心"经常一起出现。

再往前一步是**换根 DP（rerooting DP）**。很多题会问"以每个点为根时，答案分别是多少"，比如"每个点到其他所有点的距离之和"。每个点都跑一遍遍历是 `O(n^2)`；换根 DP 的做法是先以 1 为根算出一份答案，再利用"换个根只影响上面和下面两块"的性质，`O(1)` 把答案从父亲推到儿子，一次遍历算出所有点。

这里只要求你知道"换根"三个字指的是什么：**答案从根传给儿子，传的时候减掉儿子那一块、加上剩下的那一块**。具体怎么减怎么加，要看题目的答案是怎么定义的，等你写第一道换根题再回来翻这一段。

## 本章小结

> **记住这三句**
> ① 树上的"上下"是按根按出来的：先一次 BFS 拿到 `fa`、`depth`、`order`，倒着扫 `order` 就是后序。
> ② 求最远两点用两次遍历；求两点最近公共祖先用倍增跳表，一次询问 `O(log n)`。
> ③ 树形 DP 的状态只放"子树外面需要知道的信息"，合并时先算儿子、再算自己。
