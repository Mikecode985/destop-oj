# 附录 C　贵阳主题练习 40 题

本附录 40 道题均为本书自拟，用贵阳场景包装，不来自任何平台题库。题目按章排列，第 2～31 章每章至少 1 道，标题括号注明章节与知识点，末尾 ★ 表示难度（★ 基础、★★ 提高、★★★ 挑战）。每题只给一句提示、不给代码，输入输出与数据范围都写全。

## C.1 第一部分　热身与 C++ 基础（第 2～3 章）

### C-01　贵阳地铁一号线的日客流（第 2 章·数组与类型）　★

**题意**：给出 1 号线 n 个站某日的进站人次。输入 n（1 ≤ n ≤ 10^5）和 n 个整数（0 ≤ a[i] ≤ 10^9），输出总客流与客流最大站的站号（并列取小）。

**提示**：总和能到 10^14，用 `long long` 累加。

### C-02　青云市集按价格排序（第 3 章·sort 与自定义比较）　★★

**题意**：市集有 n 个摊位，各有价格和名字。输入 n（1 ≤ n ≤ 10^5）和 n 行"名字 价格"，按价格升序输出摊名，同价按名字字典序升序。

**提示**：结构体加 `sort`，先比价格再比名字。

### C-03　地铁站名速查（第 3 章·map）　★★

**题意**：给出 n 条"线路号 站名"记录与 m 次询问，每次问某站是否在某条线上。输入 n, m（1 ≤ n, m ≤ 10^5），每次输出 `Yes` 或 `No`。

**提示**：用 `map<string, set<int>>` 记站名到线路集合。

## C.2 第二部分　算法的第一性原理（第 4～7 章）

### C-04　一步算完的求和（第 4 章·复杂度）　★

**题意**：求 1+2+…+n 对 10^9+7 取余的结果。输入 n（1 ≤ n ≤ 10^9），输出这个余数。

**提示**：循环会超时；用 `n*(n+1)/2`，先乘后除。

### C-05　肠旺面馆的一周营业额（第 5 章·模拟）　★

**题意**：老周记下一周 7 天营业额，-1 表示店休。输入 7 个整数（-1 或 0 ≤ 营业额 ≤ 10^6），输出营业天数、总营业额和日均营业额（向下取整）。

**提示**：店休不计天数也不计入总和，分母是营业天数。

### C-06　地铁分段计价（第 5 章·模拟与分类讨论）　★★

**题意**：某观光线按站数计价：1～4 站 2 元，5～9 站 3 元，10～15 站 4 元，16 站及以上每满 5 站加 1 元（不足按 5 站算），最高 8 元。输入 s（1 ≤ s ≤ 60），输出票价。

**提示**：先列“区间到价格”的分支表，再处理 16 站以上。

### C-07　丝娃娃的配料组合（第 6 章·二进制枚举）　★★

**题意**：有 n 样菜，第 i 样满足度是 a[i]，一张皮最多包 k 样、每样最多选一次。输入 n, k（1 ≤ n ≤ 20，1 ≤ k ≤ 8）和 n 个满足度（1 ≤ a[i] ≤ 100），输出最大满足度之和。

**提示**：用 `1` 到 `(1<<n)-1` 枚举所有子集，n ≤ 20 正好。

### C-08　青岩古镇小吃街的问价（第 7 章·二分查找）　★★

**题意**：小吃街 n 家店的价格已按非降序排好，m 次询问各给预算 x，找价格严格大于 x 的店中价格最小的一家。输入 n, m（1 ≤ n, m ≤ 10^5）、n 个价格（1 ≤ 价格 ≤ 10^9）和 m 个 x，每次输出该价格，没有输出 -1。

**提示**：有序数组上找“第一个大于 x”，用 `upper_bound`。

### C-09　花溪公园的木板（第 7 章·二分答案）　★★★

**题意**：公园有 n 段木板，第 i 段长 L[i]，要切出至少 k 段等长木板，边角料可弃。输入 n, k（1 ≤ n ≤ 10^5，1 ≤ k ≤ 10^9）和 n 个长度（1 ≤ L[i] ≤ 10^9），输出每段最长长度，切不出输出 0。

**提示**：长度越长越难切够 k 段，二分长度后累加各段段数。

## C.3 第三部分　经典算法思想（第 8～13 章）

### C-10　花溪公园的一日活动（第 8 章·区间调度）　★★

**题意**：一天有 n 个活动，第 i 个从 s[i] 到 t[i]，同一时刻只能参加一个（首尾相接不算冲突）。输入 n（1 ≤ n ≤ 10^5）与 n 组起止时间（0 ≤ s[i] < t[i] ≤ 10^9），输出最多参加几个。

**提示**：按结束时间从早到晚排序，能参加就参加。

### C-11　黔灵山的台阶（第 9 章·递归）　★

**题意**：上山有 n 级台阶，一步可迈 1 级或 2 级，问有多少种走法。输入 n（1 ≤ n ≤ 40），输出走法数。

**提示**：`f(n) = f(n-1) + f(n-2)`，出口 `f(1) = 1`、`f(2) = 2`。

### C-12　贵阳房价的涨跌对（第 10 章·分治与逆序对）　★★★

**题意**：给连续 n 天房价，若 i < j 且第 i 天价格高于第 j 天，(i, j) 就是一个涨跌对。输入 n（1 ≤ n ≤ 10^5）和 n 个价格（1 ≤ 价格 ≤ 10^9），输出涨跌对总数。

**提示**：这就是逆序对，归并合并时数一数，答案用 `long long`。

### C-13　黔灵山猕猴的活动区（第 11 章·DFS）　★★

**题意**：后山划成 n 行 m 列格子，1 是树林、0 是空地，猕猴只能沿上下左右在树林间走。输入 n, m（1 ≤ n, m ≤ 1000）和这张 0/1 地图，输出最大连通树林块的格子数。

**提示**：遇到没访问过的 1 就 DFS 计数；10^6 格递归可能爆栈。

### C-14　从喷水池到龙洞堡机场（第 12 章·BFS）　★★

**题意**：地铁有 n 个站、m 条相邻关系（一条坐一站，双向），问从喷水池到龙洞堡机场最少坐几站。输入 n, m（1 ≤ n ≤ 10^5，0 ≤ m ≤ 2×10^5）、m 条边和起终点，输出最少站数，走不到输出 -1。

**提示**：无权图最短路用 BFS，第一次到终点时的层数就是答案。

### C-15　一场雨之后（第 12 章·多源 BFS）　★★★

**题意**：一场雨后 n 行 m 列街区里有多处积水，水每分钟向上下左右漫一格，墙挡水。输入 n, m（1 ≤ n, m ≤ 1000）和地图（0 可漫、1 是墙），输出水淹到所有可漫格子的最晚时间；有格子淹不到则输出 -1。

**提示**：所有水源先入队，这是多源 BFS；答案取最大距离。

### C-16　数博会的志愿者站位（第 13 章·回溯）　★★★

**题意**：在 n×n 展馆方阵里安排 n 名志愿者，任意两人不同行、不同列、不同斜线。输入 n（1 ≤ n ≤ 8），输出方案总数。

**提示**：一行一行放，用三个数组标记列和两条对角线。

## C.4 第四部分　数据结构（第 14～18 章）

### C-17　肠旺面的碗（第 14 章·栈）　★

**题意**：碗上印着 `(` 和 `)`，一串碗按顺序摞起、取出，每个 `)` 都要与前面的 `(` 就近配对，过程中不能有多余的 `)`。输入一个长度不超过 10^5 的括号串，输出 `Yes` 或 `No`。

**提示**：遇 `(` 入栈，遇 `)` 弹出，最后栈空才合法。

### C-18　排队时谁挡了视线（第 14 章·单调栈）　★★

**题意**：排队的人身高 h[i]，对每人求右边第一个比他高的人的位置。输入 n（1 ≤ n ≤ 10^5）和 n 个身高（1 ≤ h[i] ≤ 10^9），按顺序输出对应下标，没有则输出 0。

**提示**：从右往左扫，维护身高单调递减的栈。

### C-19　青云市集找重复摊位（第 15 章·哈希）　★

**题意**：市集有 n 个摊位，摊位号是 1 到 10^9 的整数，恰有一个号出现两次。输入 n（2 ≤ n ≤ 10^5）和 n 个摊位号，输出那个重复的号。

**提示**：边读边塞进 `unordered_set`，插入失败的就是答案。

### C-20　贵阳北站的第 k 高等候分（第 16 章·堆）　★★

**题意**：候车区 n 位乘客各有等候分值，求第 k 高的分值。输入 n, k（1 ≤ k ≤ n ≤ 10^5）和 n 个分值（1 ≤ 分值 ≤ 10^9），输出第 k 大的分值。

**提示**：维护大小为 k 的小根堆，堆顶即第 k 大。

### C-21　老小区的亲戚（第 17 章·并查集）　★★

**题意**：老小区有 n 户人家、m 条"两家是亲戚"的关系（可传递），还有 q 次询问"这两家是不是亲戚"。输入 n, m, q（1 ≤ n ≤ 10^5，0 ≤ m ≤ 2×10^5，1 ≤ q ≤ 10^5）与关系、询问，每次输出 `Yes` 或 `No`。

**提示**：合并每条关系；询问时比两个元素所在集合的根。

### C-22　地铁客流统计（第 18 章·树状数组）　★★★

**题意**：线路上 n 个站，q 次操作：`1 x v` 表示第 x 站客流增加 v，`2 l r` 询问第 l 到第 r 站的客流之和。输入 n, q（1 ≤ n, q ≤ 2×10^5），对每次询问输出答案。

**提示**：单点修改加区间查询就是树状数组，区间和用前缀和相减。

## C.5 第五部分　图论（第 19～22 章）

### C-23　贵阳地铁有几片网（第 19 章·图的遍历）　★★

**题意**：已开通的站和相邻关系看成无向图，问分成几个连通块（没接进线网的站各算一块）。输入 n, m（1 ≤ n ≤ 10^5，0 ≤ m ≤ 2×10^5）与 m 条边，输出连通块个数。

**提示**：对每个没访问的点做一次 DFS/BFS，每开一次新搜索就多一块。

### C-24　从贵阳北站到青岩古镇（第 20 章·最短路）　★★★

**题意**：n 个路口、m 条双向道路，第 i 条要 w[i] 分钟，求 s 到 t 的最短时间。输入 n, m, s, t（1 ≤ n ≤ 10^5，0 ≤ m ≤ 2×10^5，1 ≤ w[i] ≤ 10^9），走不到输出 -1。

**提示**：边权为正，用堆优化 Dijkstra，距离用 `long long`。

### C-25　有多少条一样快的路（第 20 章·最短路计数）　★★★

**题意**：用上面那张地图，问有多少条路线的时间恰好等于最短时间。输入 n, m, s, t（1 ≤ n ≤ 10^5，0 ≤ m ≤ 2×10^5），输出方案数对 10^9+7 取余的结果。

**提示**：Dijkstra 松弛时维护方案数：更短就覆盖，相等就累加。

### C-26　把区县都连起来（第 21 章·最小生成树）　★★★

**题意**：贵阳 n 个区县要修若干条公路全部连通，m 条候选公路各带造价。输入 n, m（1 ≤ n ≤ 10^5，0 ≤ m ≤ 2×10^5）与每条边的两个端点、造价（1 ≤ 造价 ≤ 10^9），输出最小总造价；连不通输出 -1。

**提示**：Kruskal：按造价排序边，用并查集判断成不成环。

### C-27　小区里最远的两栋楼（第 22 章·树的直径）　★★

**题意**：小区道路网是一棵树：n 栋楼由 n-1 条带长度的小路连起来。输入 n（2 ≤ n ≤ 10^5）和每条边的两个端点与长度（1 ≤ 长度 ≤ 10^9），输出任意两栋楼之间最远的距离。

**提示**：从任意点 DFS 找到最远的 A，再从 A 找到最远的 B。

## C.6 第六部分　动态规划（第 23～27 章）

### C-28　高坡云顶的梯田（第 23 章·数字三角形）　★★

**题意**：梯田第 i 行有 i 块，每块有收成值；从最上面一块出发，每步只能往左下或右下走，走到最下面一行。输入 n（1 ≤ n ≤ 1000）和这个三角形（0 ≤ 收成 ≤ 10^4），输出最大收成之和。

**提示**：从下往上递推，`dp[i][j] = a[i][j] + max(dp[i+1][j], dp[i+1][j+1])`。

### C-29　行李箱装纪念品（第 24 章·0-1 背包）　★★

**题意**：带回 n 件纪念品，第 i 件重 w[i]、价值 v[i]，行李箱最多装 W 克。输入 n, W（1 ≤ n ≤ 1000，1 ≤ W ≤ 1000）与 n 组 w[i]、v[i]（1 ≤ w[i] ≤ W，1 ≤ v[i] ≤ 10^4），输出最大总价值。

**提示**：0-1 背包，一维数组要倒序枚举容量。

### C-30　公交售票机找零（第 24 章·完全背包）　★★★

**题意**：售票机有 n 种面值硬币，每种无限枚，凑出 m 元最少用几枚。输入 n, m（1 ≤ n ≤ 100，1 ≤ m ≤ 10^5）和 n 种面值（1 ≤ 面值 ≤ 10^5），凑不出输出 -1。

**提示**：完全背包求最小值，一维数组正序枚举容量。

### C-31　花溪河边的石头（第 25 章·区间 DP）　★★★

**题意**：河边 n 堆石头排成一行，每次合并相邻两堆，代价是两堆数之和，直到只剩一堆。输入 n（1 ≤ n ≤ 300）和 n 堆石头数（1 ≤ 每堆 ≤ 10^4），输出最小总代价。

**提示**：先枚举区间长度再枚举断点，区间和用前缀和。

### C-32　连续的好天气（第 25 章·LIS）　★★★

**题意**：给连续 n 天气温，求最长"不下降"子序列长度，子序列不要求连续。输入 n（1 ≤ n ≤ 10^5）和 n 个气温（1 ≤ 气温 ≤ 10^9），输出这个长度。

**提示**：`dp` 记“长度为 i 的不下降子序列结尾的最小值”，可二分。

### C-33　数博会排班（第 26 章·状压 DP）　★★★

**题意**：有 n 个岗位、m 名志愿者，每人能胜任若干岗位，每岗恰好 1 人、每人最多 1 岗，问方案数。输入 n, m（1 ≤ n ≤ m ≤ 20）和每人能胜任的岗位集合，输出方案数。

**提示**：用二进制表示“岗位排没排满”，`dp[mask]` 按人数转移。

### C-34　检修车跳站（第 27 章·单调队列优化 DP）　★★★

**题意**：检修车从 1 号站开到 n 号站，每次最多往前跳 k 站，每落一站付出该站检修时间 a[i]（起终点也付）。输入 n, k（1 ≤ k ≤ n ≤ 10^5）和 a[1..n]（1 ≤ a[i] ≤ 10^9），输出最小总时间。

**提示**：`dp[i] = a[i] + min(dp[i-k..i-1])`，用单调队列维护窗口最小值。

## C.7 第七部分　字符串、数学与实战（第 28～31 章）

### C-35　贵阳地名检索（第 28 章·KMP）　★★★

**题意**：给文本 T 和模式串 P，统计 P 在 T 中出现次数（可重叠）。输入两行，T 和 P 的长度都不超过 10^6，只含小写字母，输出出现次数。

**提示**：KMP 匹配到末尾后把 `j` 回退到 `next[j]`，重叠也能数。

### C-36　数博会的加密展台（第 29 章·快速幂）　★★

**题意**：算 a 的 b 次方对 p 取余。输入 a, b, p（0 ≤ a ≤ 10^9，0 ≤ b ≤ 10^18，1 ≤ p ≤ 10^9），输出结果（约定 0 的 0 次方等于 1）。

**提示**：把指数按二进制拆开，底数不断平方。

### C-37　胸牌编号里的素数（第 29 章·筛法）　★★

**题意**：1 到 n 每名志愿者一块胸牌，问胸牌号是素数的有几块。输入 n（1 ≤ n ≤ 10^7），输出 1 到 n 中素数的个数。

**提示**：线性筛或埃氏筛预处理到 n，再数标记。

### C-38　丝娃娃选菜（第 30 章·组合数取模）　★★★

**题意**：有 n 样菜，从中选 m 样包进丝娃娃，问有多少种选法（不计顺序）。输入 n, m（1 ≤ m ≤ n ≤ 10^6），输出 C(n, m) 对 10^9+7 取余的结果。

**提示**：预处理阶乘和阶乘逆元，逆元用费马小定理。

### C-39　机房的权限位（第 31 章·位运算）　★

**题意**：机房的每个权限用不超过 10^18 的整数表示。输入 n（1 ≤ n ≤ 10^5）和 n 个整数，输出它们按位异或的结果，以及二进制中 1 的总个数。

**提示**：数 1 用 `x &= x - 1` 反复消最低位的 1。

### C-40　一百位的胸牌号（第 31 章·高精度）　★★

**题意**：胸牌号可能长达 1000 位，要把两个这样的正整数相加。输入两行，各是一个不超过 1000 位、没有前导零的十进制正整数，输出它们的和。

**提示**：两个数倒着存，从低位往高位逐位相加并处理进位。
